## Projects

**[Living Language Lab](https://github.com/alperenbayir/LivingLanguageLab)** — VR vocabulary game
for the Meta Quest 3, written in C# with Unity 6 and the XR Interaction Toolkit. Objects in a
kitchen are scanned with the controller and shown on an in-game tablet with the German word, its
article and audio; speech input goes through the Meta Voice SDK and example sentences come from a
locally hosted Ollama model. Four-person Fachprojekt — I did the game design, merged the prototype
scenes into one build, and wrote the progression logic, the scan mechanic and the tablet UI.

**[sopra-tauchen-card-game](https://github.com/fluxlious/sopra-tauchen-card-game)** — two-player
card game in Kotlin, on the BoardGameWork GUI framework. Designed on the three-layer principle —
entity, service and GUI — with drag-and-drop card play, animations, and unit tests over the rules.
Individual university project.

**Cascadia** — the board game implemented in Kotlin on the same framework, with client-server
multiplayer and bot opponents, and the board held as a graph of hex-placed tiles. Group project;
I was the main author of the GUI layer. Not public.

**[brandourjersey](https://github.com/fluxlious/brandourjersey)** — selling ad spots on the
jersey of our student team in TU Dortmund's Campusliga. Live at
[brandourjersey.com](https://brandourjersey.com) — a static page on GitHub Pages with a Cloudflare
Worker behind it handling checkout, payment webhooks and the spot reservations; payments are wired
up but not switched on yet.

**[meowmi2](https://github.com/fluxlious/meowmi2)** — browser game prototype in plain JavaScript,
HTML and CSS.
